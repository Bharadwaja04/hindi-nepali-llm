# reports/

The original phase reports and the raw metrics behind them, kept as a historical record. They were written during the course and
contain claims that this repository's [known issues](../docs/known-issues.md) corrects, so read the docs first.

| Folder | Contents |
|---|---|
| `phase1/` | Corpus, tokenizer and vocabulary-size experiments (`phase1_report.md`) and the language-selection note |
| `phase2/` | Pretraining and base-model evaluation: Hindi training log, generation samples and metrics, attention statistics, Nepali metrics |
| `phase3/` | Reasoning fine-tuning: before/after examples for both languages. `phase3_report_original.md` is the unedited report (it still contains placeholders) |
